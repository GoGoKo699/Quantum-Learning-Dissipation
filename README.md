# Quantum Learning Dissipation

**Question:** What work deficit is unavoidable when a device processes copies of an unknown pure qubit sequentially and retains only classical information between arrivals?

The proposed comparison is between adaptive classical records and a bounded coherent memory, with all records and the controller restored or charged at the end. The candidate scaling laws are **research targets, not verified theorems**. The first task is to reconcile online-learning regret with a complete physical work ledger.
